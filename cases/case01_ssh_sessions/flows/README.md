# Flow export — case01_ssh_sessions

`case01_flows.csv` is a **tabular flow export derived from Zeek `conn.log`**. Independent NetFlow exporter records from `nfpcapd`/`nfdump` 1.7.10-release are now under `cases/<case>/netflow/` (see `report/netflow_reconciliation.md`); this CSV is still a Zeek-derived view, not a NetFlow record. Zeek `conn.log` is itself a bidirectional flow log; this CSV simply presents each connection as one flow record for readers who want a flow-oriented view. It is reconciled against tshark TCP/UDP stream counts in `report/flows_reconciliation.md`. Provenance: Zeek 9.0.1 JSON `conn.log`, generated from the sealed pcap with `tools/run_zeek.sh`.
